# 🔐 Flask Password Generator

A secure, lightweight, and responsive web-based **Random Password Generator** application built with Python and Flask. This project allows users to generate customizable, strong passwords instantly based on their preferred length and criteria.

## 🚀 Live Preview
* **Length Control:** Choose any password length between 8 and 32 characters.
* **Symbol Customization:** Toggle feature to include or exclude complex symbols (`@`, `#`, `$`, etc.).
* **Instant Generation:** Generates a cryptographically strong random sequence in real-time.

## 🧠 Concepts Covered & Learning Journey

This project was built from scratch as part of my web development and core backend logic learning journey. During this build, I integrated advice from **AI tools (Gemini/ChatGPT)** and utilized **Google search documentation** to solve implementation bottlenecks.

Key programming concepts used include:
* **Flask Framework:** Handling single-file routing, web requests (`GET`, `POST`), and session management.
* **Random Module (`random.choice`):** Dynamically selecting unpredictable elements from a pool.
* **String Manipulation (`string` module):** Combining lowercase, uppercase, digits, and special characters programmatically.
* **Control Flow & Loops:** Implementing Python arrays and `for` loops to stitch password characters efficiently.
